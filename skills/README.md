# Skills para Claude

Skills no formato `SKILL.md` (frontmatter com `name` e `description` + instruções).

| Skill | Para quê |
|---|---|
| [`auditoria-seo-geo`](auditoria-seo-geo/SKILL.md) | Audita a presença em buscadores e em respostas de IA e entrega um plano priorizado |
| [`pesquisa-de-mercado`](pesquisa-de-mercado/SKILL.md) | Pesquisa de mercado estruturada, com fontes, concorrentes e oportunidades |
| [`relatorio-executivo`](relatorio-executivo/SKILL.md) | Relatório de uma página para a liderança, com conclusão primeiro |
| [`landing-page-conversao`](landing-page-conversao/SKILL.md) | Estrutura e texto de landing page orientada a conversão |
| [`especificacao-dashboard`](especificacao-dashboard/SKILL.md) | Indicadores, fontes e layout de um dashboard antes da construção |

## Como instalar
- **Claude Code**: copie a pasta da skill para `.claude/skills/` do projeto.
- **Claude (app)**: compacte a pasta da skill em `.zip` e envie na área de Skills das configurações.
